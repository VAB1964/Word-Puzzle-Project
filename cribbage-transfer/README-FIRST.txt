CRIBBAGE TRANSFER PACKAGE

The cribbage/ folder contains the complete portable source for the working
Cribbage Card Room. Give this ZIP and CURSOR-PROMPT.txt to Cursor while the
Word-Puzzle-Project is open.

The package deliberately uses relative asset paths so the finished game can
run at https://vabgames.com/cribbage/.

Do not remove the existing hosted game until the VABGames copy has been tested.
